# 스킬 폴더

Rig는 스킬 폴더에서 `SKILL.md` 파일을 찾아 라이브러리를 구성합니다.

## 기본 폴더

**모든 스킬**의 **전역** 목록에는 다음 기본 폴더가 표시됩니다.

| 에이전트 | 경로 |
| --- | --- |
| Codex | `~/.agents/skills`, `~/.codex/skills` |
| OpenCode | `~/.config/opencode/skills` |
| Claude | `~/.claude/skills` |
| Hermes | `~/.hermes/skills` |
| Cursor | `~/.cursor/skills` |

존재하지 않는 폴더는 건너뜁니다. 설치한 에이전트의 폴더만 사용하면 됩니다.

## 프로젝트 추가

**프로젝트 추가**로 로컬 폴더를 선택하면 하위 패키지와 사용자 지정 폴더까지 스캔합니다. 폴더를 펼쳐 스킬을 확인하세요. Rig는 추가한 폴더 목록을 앱 데이터 디렉터리에 저장하고, 실행할 때 각 경로가 존재하는지 확인합니다.

폴더가 삭제되거나 이동하면 선택 목록에서 제거하고 **모든 스킬**로 돌아갑니다.

의존성·빌드·Git·백업·이전 버전의 보관 폴더는 현재 라이브러리에서 제외됩니다.

## 스킬 숨기기

스킬을 우클릭해 **Rig에서 숨기기**를 선택하세요. 로컬 화면 설정만 바뀌며 파일은 에이전트가 사용할 수 있는 원래 위치에 남습니다. **숨김**에서 **Rig에 표시**를 선택하면 다시 보입니다.

폴더 전체를 숨기려면 폴더 제목을 우클릭해 **Rig에서 폴더 숨기기**를 선택하거나 옆의 눈 아이콘을 누르세요. 하위 폴더와 나중에 추가하는 스킬도 함께 숨겨집니다. **숨김**에서 **Rig에 폴더 표시**를 선택하면 복원됩니다. 별도로 숨긴 스킬과 하위 폴더는 숨김 상태를 유지합니다.

이전 버전이 실제로 이동한 파일은 **보관된 파일**로 표시됩니다. **파일 복원**을 선택하면 원래 위치로 되돌릴 수 있습니다.

## 스킬 파일 조건

다음 조건을 모두 만족하면 유효한 스킬로 인식합니다.

- 파일 이름이 `SKILL.md`입니다.
- 파일이 비어 있지 않습니다.
- YAML 프런트매터가 있습니다.
- 프런트매터의 `name`과 `description`이 비어 있지 않습니다.
- 마크다운 본문이 비어 있지 않습니다.

예시:

```md
---
name: accessibility-audit
description: WCAG 지침에 따라 웹 접근성을 검토하고 개선합니다.
---

접근성, 키보드 조작 또는 스크린 리더 동작을 개선할 때 사용합니다.
```

## 유효성 확인

조건을 만족하지 않는 스킬도 **유효하지 않음** 표시와 함께 목록에 나타납니다. 스킬을 선택해 오류 메시지를 확인하고 해당 `SKILL.md` 파일을 수정하세요.

프런트매터 누락, 잘못된 YAML, `name` 또는 `description` 누락, 빈 본문 등이 대표적인 오류입니다.
