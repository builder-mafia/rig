# Rig 문서

Rig는 Claude Code, Codex, OpenCode와 프로젝트의 `SKILL.md` 파일을 관리하는 로컬 데스크톱 워크스페이스입니다.

전역·프로젝트 스킬을 폴더별로 탐색하고, 지침을 수정하고 복사하며, 필요 없는 스킬을 화면에서 숨기고, 설치 프롬프트로 공유하세요.

## Rig가 읽는 파일

Rig는 `SKILL.md` 파일로 저장된 에이전트 스킬을 읽습니다. 유효한 스킬에는 `name`과 `description`을 담은 YAML 프런트매터와 비어 있지 않은 마크다운 본문이 필요합니다.

```md
---
name: example-skill
description: 구체적인 예시가 필요할 때 사용하는 스킬입니다.
---

여기에 스킬 지침을 작성합니다.
```

## 주요 기능

- **폴더 탐색**: 전역 폴더, 프로젝트, 하위 폴더를 펼쳐 확인합니다.
- **여러 에이전트 지원**: Claude Code, Codex, OpenCode와 프로젝트의 스킬을 함께 탐색합니다.
- **스킬 편집**: 스킬을 선택하면 프런트매터를 포함한 `SKILL.md` 전체를 수정할 수 있습니다. 입력을 잠시 멈추면 자동 저장되며, Command/Ctrl+S로 즉시 저장할 수 있습니다. 저장 후 상단 가운데에 알림이 표시됩니다. 다른 앱에서 파일을 수정한 경우 초안을 유지하고 저장 전에 파일을 다시 불러오도록 안내합니다.
- **에디터에서 열기**: 헤더의 아이콘으로 설치된 Cursor, VSCode, WebStorm, Zed에서 스킬을 열거나 Finder에서 파일을 표시합니다. 기록과 파일 상세 정보는 더보기 메뉴에서 확인합니다.
- **간편한 공유**: 헤더나 우클릭 메뉴의 **공유**를 누르면 AI용 설치 프롬프트를 바로 복사하고 알림을 표시합니다.
- **지침 복사**: 헤더의 더보기 메뉴에서 마크다운 본문을 복사합니다.
- **폴더 간 스킬 복사**: 스킬을 하나 이상 선택하고 우클릭 메뉴에서 **복사**를 선택합니다. 검색된 프로젝트가 먼저 표시되며, 선택한 프로젝트의 `.agents/skills`에 복사합니다. 아래의 **직접 선택**으로 다른 대상 폴더를 고를 수도 있습니다. 확인 단계에서 스킬과 대상 폴더를 확인한 뒤 **복사**를 누르세요. 원본을 유지하면서 스킬 폴더 전체를 복사하고, 이름이 겹치면 `-copy` 접미사를 붙이며, 완료 알림을 표시합니다.
- **Rig에서 숨기기**: 파일을 이동하거나 비활성화하지 않고 화면에서만 숨깁니다.
- **언어와 화면 설정**: 설정에서 한국어·영어·시스템 언어와 라이트·다크·시스템 테마를 선택합니다. 설정은 다시 실행해도 유지되며, 스킬 이름과 지침은 바뀌지 않습니다.
- **Rig 버전 기록**: 기존 스냅샷과 복원 시 생성된 복구용 버전을 비교하고 복원합니다.

## 로컬 실행

스킬 탐색·읽기·정리·복원은 모두 내 Mac에서 실행됩니다. 스킬 파일은 Rig 서버에 업로드되지 않습니다. 설치 프롬프트를 다른 서비스에 전달할지는 직접 선택합니다.
