# Rig Documentation

Rig is a local desktop workspace for the `SKILL.md` files used by Claude Code,
Codex, OpenCode, and your projects.

Browse global and project skills by folder, edit and copy instructions, hide
skills from your Rig view, and share them with an installation prompt.

## What Rig Reads

Rig focuses on agent skills stored as `SKILL.md` files. A valid skill should include YAML frontmatter with a `name` and `description`, followed by non-empty markdown content.

```md
---
name: example-skill
description: Use this skill when you need a concrete example.
---

Skill instructions live here.
```

## Features

- **Folder navigation**: Expand global roots, projects, and nested folders
- **Multiple providers**: Browse skills from Claude Code, Codex, OpenCode, and project folders together
- **Edit skills**: Select a skill to edit the complete `SKILL.md`, including frontmatter. Changes save automatically after typing pauses; Command/Ctrl+S saves immediately. A notification appears at the top center after saving. If another app changes the file, Rig keeps your draft and asks you to reload before saving.
- **Open in an editor**: Header icons open the skill in installed Cursor, VSCode, WebStorm, or Zed applications; Finder reveals the file. History and file details are available in the more menu.
- **Simple sharing**: Click **Share** in the header or context menu to copy an AI-ready installation prompt immediately, with a confirmation toast.
- **Copy instructions**: Use the header’s more menu to copy the markdown body
- **Copy skills between folders**: Right-click one or more selected skills and choose **Copy**. Detected projects appear first and copy into `.agents/skills`; choose **Custom** below to select any destination folder. Review the skill and destination in the confirmation step, then choose **Copy**. Rig copies the full skill folder, preserves the original, gives duplicates a `-copy` suffix, and shows completion in a toast.
- **Hide from Rig**: Hide skills locally without moving or disabling their files
- **Language and appearance**: Open Settings to choose English, Korean, or the system language, and a light, dark, or system theme. Your choices persist across restarts; skill names and instructions remain unchanged.
- **Rig version history**: Compare and restore existing snapshots and recovery versions created during restores

## Runs Locally

Browsing, reading, organizing, and restoring skills all happen on your Mac. Skill files are never uploaded to a Rig server. You choose whether to share an install prompt with another service.
